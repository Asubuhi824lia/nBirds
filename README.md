#### Принципы сортировки

##### Общее

- Механизм сортировки
  - по ASCII-коду
  - по первому символу (*)
- Порядок сортировки
  - первична сортировка по __количеству__ «видов» в «семействе»
  - сортировка по __алфавиту__ происходит только среди «семейств» с одинаковым __количеством__ «видов»
  - названия на латыни в сортировке приводятся отдельно

##### Сортировка по алфавиту

- `ASC`
    - от первой до последней буквы (алфавита)
- `DESC`
    - от последней до первой буквы (алфавита)
