#### Принципы сортировки

##### Общее

- Механизм сортировки
  - по ASCII-коду
  - по первому символу (*)
- Порядок сортировки
  - первична сортировка по __количеству__ «видов» в «семействе»
  - сортировка по __алфавиту__ происходит только среди «семейств» с одинаковым __количеством__ «видов»

##### Порядок сортировки
С учетом значения «флажка» языкового взаиморасположения (латынь / локализация)

`ASC`
- От первой до последней буквы **алфавита**
- ###### По значению «флажка»
    - `default`:
      - A-Z, А-Я
    - `checked`:
      - А-Я, A-Z

`DESC`
- От последней до первой буквы **алфавита**
- ###### По значению «флажка»
    - `default`:
    - `checked`:
      - Я-А, Z-A
