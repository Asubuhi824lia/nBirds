## Функционал

### Список названий (результирующий показ)

Главная **область**, отображающая информацию, вид которой определяется **фильтрами** и выбираемыми значениями **сортировки** и **поиска** (_описаны далее_).

#### Формат отображения

1. Отображаются данные «группы» «семейств», включающих **количество** «видов», соответствующее выбранному (в **табах**) «диапазону» (_указан в **заголовке**_)
2. Отображаются данные «группы», разделенные по блокам—«секциям» на более детальные «диапазоны» (_указан в **подзаголовке**_)
3. Для каждого «семейства» указано **количество** «видов» в нем

#### Специфика отображения числа **подзаголовка** в «секции»

- Без отображения
  - условия
    - в «диапазоне» «видов» отсутствуют «семейства»
  - эффект
    - «секция» для показа **отсутствует**
   
- Единственной цифрой
  - условия
    - **количество** «видов» меньше чем **10**
    - **количество** «семейств» в «секции» составляет **1**
    - **количество** «видов» для **каждого** «семейства» в «секции» **одинаково**
  - эффект
    - в **подзаголовке** «секции» отображается конкретная цифра
    - в строке с названием «семейства» отображение числа «видов» **отсутствует**
   
- Нижней границей «поддиапазона»
  - условия
    - _отсутствие каждого из условий для вариантов выше_
  - эффект
    - в **подзаголовке** «секции» отображается нижняя граница «поддиапазона» со знаком «+»
    - в каждой строке с названием «семейства» отображается число «видов» после знака «—»
   
#### Дополнительные возможности отображения

1. Иные «режимы» показа названия на **латыни**
2. Иные «режимы» показа **альтернативных** названий
3. Отображение схожих «корней» в названиях

#### Принципы сортировки

##### Общее

- Механизм сортировки
  - по ASCII-коду
  - по первому символу (*)
- Порядок сортировки
  - первична сортировка по __количеству__ «видов» в «семействе»
  - сортировка по __алфавиту__ происходит только среди «семейств» с одинаковым __количеством__ «видов»

##### Порядок сортировки
С учетом значения «флажка» языкового взаиморасположения (латынь / локализация)

`ASC`
- От первой до последней буквы **алфавита**
- ###### По значению «флажка»
    - `default`:
      - A-Z, А-Я
    - `checked`:
      - А-Я, A-Z

`DESC`
- От последней до первой буквы **алфавита**
- ###### По значению «флажка»
    - `default`:
    - `checked`:
      - Я-А, Z-A
